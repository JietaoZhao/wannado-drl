# wannado-drl Universal AI Collaboration Rules

This repository uses `wannado-drl` under the open `AGENTS.md` + `.agents/skills/wannado-drl/SKILL.md` standard (compatible across Cursor, Antigravity, Codex, Claude Code, Windsurf, and other AI coding agents).

- **Scope & Sibling Coexistence (`wannado-adv`)**: Activate `wannado-drl` ONLY for Problem-to-MDP co-design, DRL training/comparison/auditing, and RL experiment reporting (`./drl_lab/`). If both `wannado-drl` and `wannado-adv` are present and the user asks to test **adversarial robustness / perturbation attacks** on an already-trained RL policy, do NOT re-trigger `wannado-drl` Stage-0 dialogs or alter `./drl_lab/` — hand off directly to `./adv_eval/` (`wannado-adv`) and apply any saved frozen `obs_rms_state` (`mean`, `var`) via differentiable PyTorch ops inside the victim wrapper.

Whenever solving or benchmarking RL, obey this 5-stage DRL discipline:

1. **Traverse First, Share AI Understanding, Showcase Arsenal & Pop Goal Dialog**: Run `wannado-drl inspect .` first. Never ask blindly "what does your project do?" — explain your codebase understanding + observed clues first (aligning if unclear), showcase the versioned `wannado-drl` RL arsenal (`wannado-drl arsenal`, Classic Foundations -> 2025 Frontier SOTA), and **pop a Goal Confirmation Dialog** (Option 1: confirm AI-inferred DRL objective; Option 2: let user state their goal in 1 sentence) BEFORE designing the MDP (`./drl_lab/mdp_spec.json`) or picking algorithms.
2. **Non-Intrusive External `drl_lab/` Boundary & CleanRL Single-File Ejection**: Search the DRL sea to offer both Classic Baselines and Frontier SOTA. Never scatter RL training loops inside user simulator/model files; wire everything through `./drl_lab/interface.py` (`EnvInterface`), and eject single files via `wannado-drl eject <algo_id> --dest ./drl_lab/algos` preserving `[AI-Prompt Hook]` + `optimizations_used` / `resolve_run_optimizations`.
3. **Mandatory Stage 1 Preflight + Baseline Floor Before Training**: Always run `preflight_env()` first to verify NaN/Inf, seeded reset consistency, `terminated` vs `truncated`, measured `ms/step`, Random score, and Heuristic baseline score.
4. **Zero-Jargon Plain Analogies + Algorithm Knobs + Storage Path & ETA Confirmation**: Reply in the user's conversation language. Call `explain_parameters(algos=..., preflight_report=pf)` + `estimate_runtime()` before running; explain **every technical term in plain analogies & equivalents** (episodes vs steps, `epsilon` greedy exploration, `gamma`, `ent_coef`, `clip_coef`, `group_size`, etc.), explicitly confirm **data & report storage paths** (`./drl_lab/outputs/`), and get user approval on the measured ETA.
5. **Visual Markdown Report, Zero-Hallucination Provenance & Debrief**: Run `evaluate_drl_suite(..., run_audit=True)` across multiple seeds and call `report.save(...)` + `build_post_run_debrief(report)`. Open with a plain-language verdict, highlight generated charts (`results_overview.png`/`.svg`) + Markdown summary tables in `paper_summary.md`, flag any `RigorAuditReport` traps, and **explicitly list every RL algorithm and every optimization used with verified paper citations** exclusively from `OPTIMIZATION_PROVENANCE` / `verified_bibliography` / `wannado-drl cite`.
